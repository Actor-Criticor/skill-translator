# 学术翻译规范（英文期刊论文 PDF → 中文 LaTeX 译文）

> **适用对象与用法**：本文是本流水线翻译 agent 的操作手册；开始翻译前必须通读全文，翻译每一节时逐条对齐对应章节的规则，交付前逐条勾选第 11 节清单。全部规则为强制项，可逐条判定「通过 / 不通过」。

---

## 1. 总原则

1.1 **忠实优先于流畅**：当「通顺」与「信息一致」冲突时，必须保留信息一致，牺牲流畅度。
1.2 **禁止增删**：不得添加原文没有的事实、数据、结论、因果、评价、限定语；不得删除原文的否定、限定语（not、only、may、significantly、partly）、条件与范围。
1.3 **禁止自行补全**：原文未给出的解释、机理、背景、举例，一律不得展开；确需说明的写译注（第 10 节）。
1.4 **存疑必须标注**：语义、指代、术语译名无法确定时，必须写【译注：存疑——…】；禁止猜测填空，禁止整句跳过。
1.5 **逐句对齐**：以原文句子为最小对齐单位，不得合并两句，不得把一句无对应地拆成两段（句内拆分见 3.7）。
1.6 **占位符保真**：PDF 提取中被标记为数学片段的占位符，必须在译文对应位置原样复制，不得改写、删除、新增、重排。
1.7 **逐块覆盖**：每个原文块（标题、段落、题注、表头、脚注、声明）都必须有一条对应译文；原文空块显式写「【空块】」。

## 2. 术语处理

2.1 **先建表再翻译**：动笔前建立 `glossary.md`，两列固定为「English | 中文译名」；每确定一个新术语立即写入，之后遇到同一英文术语必须回表复用。
2.2 **全篇唯一**：同一英文术语只允许一个中文译名；同一中文译名不得对应两个英文术语。定稿后逐个术语全文检索核对。
2.3 **标准译名优先**：采用学科通用译名；无标准译名时才用字面直译，并在该处写「无标准中文译名，暂译…」的译注。
   - `convolutional neural network` → 「卷积神经网络」；`ablation study` → 「消融实验」；`state-of-the-art` → 「当前最优」。
2.4 **首次出现加英文括注**，格式固定为「中文（English）」，全篇只用这一种；二次及以后只写中文。
   - `spatial attention` → 「空间注意力（spatial attention）」，后文写「空间注意力」。
2.5 **公认缩写保留，不再译**：CNN、PCR、SVM、MRI、GAN、DNA、RNA、LSTM、BERT 直接写缩写，不写中文全称也不写英文全称。
   - 原文首次给出全称＋缩写时照写：`convolutional neural network (CNN)` → 「卷积神经网络（CNN）」，后文一律写 CNN。
2.6 **人名保留原文拼写**，不音译：`Smith` 保留 `Smith`，`van der Waals` 保留原样。原文为中文姓名的罗马拼写（如 `Zhang Wei`）可回译；回译与拼音非唯一对应时保留原文。
2.7 **机构名、期刊名、会议名保留原文**，不翻译、不加书名号：`Nature`、`MIT`、`IEEE Transactions on …`。
2.8 **专名保留原文**：软件（Python、MATLAB）、算法（ResNet-50、Adam）、数据集（ImageNet、CIFAR-10）、基因与蛋白（TP53、p53）、化学物（H2O）一律照抄；斜体等排版属性随原文保留。
2.9 **禁止生造中英混排**：不得写「这个 model 效果很好」「该方法很 robust」。英文只允许出现在 2.4 的括注、2.6–2.8 的专名与第 8 节清单中。

## 3. 学术文体

3.1 **人称策略一次选定、全篇一致**：默认用「本文」；原文强调作者主动行为（we conducted、we thank）时用「我们」。同一句式不得两种人称混用。
   - `We propose a two-stage framework.` → 「本文提出一个两阶段框架。」
   - `We thank the reviewers for their comments.` → 「我们感谢审稿人的意见。」
3.2 **被动语态转主动句或无主句**，禁止直译「被」。
   - `The samples were heated to 80 °C.` → 「样品加热至 80 °C。」（禁止「样品被加热到 80 摄氏度」。）
3.3 **禁止口语化**：`a lot of` → 「大量」；`a bit` → 「略微」；`get` → 「得到」；`big` → 「显著」「较大」；`find out` → 「发现」；`look at` → 「考察」。
3.4 **消除翻译腔**：禁止「进行……的操作」「做出……的行为」；判断句按中文习惯调整主语：`This is important.` → 「这一点很重要。」；连续助词「的」不得超过两个。
3.5 **时态与人称自然化**：英文过去时叙述实验过程不必逐句加「曾经」「已经」；不得为对应时态堆砌时间副词。
3.6 **情态动词一一对应**：`must` → 「必须」；`should` → 「应」；`can` → 「可」；`may` → 「可」。不得把 `may` 译成肯定语气，也不得把 `can` 译成「必须」。
3.7 **长句必须拆分**：英文单句超过 40 词或含 3 个以上从句时，必须拆为 2–3 个中文句子；因果、让步、条件等逻辑连接必须随对应分句迁移，不得错位。
3.8 **语序调整**：中文状语前置；英文「结论＋条件」结构译成「条件＋结论」。
   - `The method fails when the noise level exceeds 0.2.` → 「当噪声水平超过 0.2 时，该方法失效。」
3.9 **连接词中文化并限用**：`however` → 「然而」；`therefore` → 「因此」；`moreover`/`furthermore` → 「此外」；`thus` → 「从而」；`in contrast` → 「相反」；`nevertheless` → 「尽管如此」。同一连接词在同一自然段内不得超过一次；原文没有连接词时不得添加。

## 4. 符号与公式周边

4.1 **变量、函数名、参数、单位、量纲、运算符一律保留拉丁字母与符号原样**，绝不译成中文。
   - `Set α = 0.05.` → 「取 α = 0.05。」（禁止「设阿尔法等于零点零五」。）
4.2 **公式周边中文表述固定用词**：`where` → 「其中」；`let` → 「设」；`denote` → 「表示」「记为」；`respectively` → 「分别为」；`for all` → 「对任意」；`such that` → 「使得」；`if and only if` → 「当且仅当」；`approximately` → 「约」。
   - `where n is the sample size` → 「其中 n 为样本量」。
4.3 **公式本体与占位符逐字复制**：不得为「更好看」改括号、改优先级、改求和上下限；公式内单位不译（`kg/m³` 保留）。
4.4 **公式编号原样保留**：原文 `Equation (3)`、`Eq. (3)`、`(3)` 的编号数值不变，正文引用统一写作「式(3)」；不得改编号、重排、新增，也不得写成「式（三）」。
4.5 **下标含义首次出现必须说明**：如 `$T_c$`（c 表示 critical，临界）→ 「其中下标 c 表示 critical（临界）」；该说明全篇只出现一次，并写入 `glossary.md`。
4.6 **公式前后标点随中文句子**：独立成行不加标点，嵌入句中按中文句法用逗号、句号。

## 5. 数字、单位与统计

5.1 **原样照抄**：数字、有效位数、上下标、百分比、量级、误差（±）、p 值、置信区间、样本量必须与原文字符串逐字符一致；禁止四舍五入、禁止单位换算、禁止补零或去零。
   - `0.050` 必须译作 `0.050`，不得写 `0.05`；`92.5%` 必须译作 `92.5%`，不得写「约 93%」。
5.2 原文换算矛盾或明显笔误时，**照抄原值并写译注**，不得自行更正。
5.3 **千分位**：4 位及以上整数去掉英文千分位逗号（`12,500` → `12500`），不得改用「万」「亿」换算；小数点保留英文写法。
5.4 **数字与单位之间**：数字与单位符号之间留一个半角空格（`80 °C`、`5 mm`、`3.2 kg`）；数字与百分号之间不留空格（`50%`）。单位必须用符号，不得写「摄氏度」「毫米」。
5.5 **数值区间**用半角连接号：`3–5`、`10–20%`；不得译成「3 到 5」「三至五」。
5.6 **统计符号保留原符号与斜体**：`p`、`t`、`F`、`r`、`n`、`N`、`M`、`SD`、`χ²` 照抄。`p < 0.05` 必须写作 `p < 0.05`，不得写成「P 值小于零点零五」。
5.7 统计缩写保留原文，首次出现加中文括注：`95% CI` → 「95% 置信区间（95% CI）」，后文写 `95% CI`；`SD`、`SE`、`OR`、`HR` 同理。
5.8 **显著性措辞**：统计语境下 `significantly` 必须译「显著」，不得省为「明显」；`not significantly` 必须保留否定；`marginally` 译「边缘显著」。

## 6. 图表与题注

6.1 **编号风格**：`Figure 1` → 「图1」；`Fig. 2` → 「图2」；`Figures 3–5` → 「图3–图5」；`Table 1` → 「表1」；`Tables 2 and 3` → 「表2、表3」。编号与「图」「表」之间不留空格，不加英文句点。
6.2 **面板对应**：`Fig. 2a` → 「图2(a)」；`Fig. 2(a,b)` → 「图2(a, b)」；`Fig. 2a–c` → 「图2(a)–(c)」。不得混用「图 2」「Fig. 2」「图2a」。
6.3 **题注完整翻译**，以「图1」或「表1」开头，后接一个空格与中文题名，末尾不加句号；题注内多句之间用中文逗号、分号。
6.4 **题注保真**：保留 (a)(b)(c) 面板标记及其描述顺序；保留题注中的符号、变量、单位、数据集名与引用标注；术语与正文术语表一致。
6.5 **图片来源行、版权行、致谢式脚注**（如 `Reprinted with permission from …`）保留原文不译。
6.6 **图内英文文字一律不翻译**：坐标轴标签、图例、流程框文字、地图标签保留英文原貌。因此译文禁止「如图所示」「如图中标注所示」这类依赖图内文字的含糊表述，必须把关键信息写进句子：
   - `As shown in the figure, the curve flattens.` → 「如图2(a)所示，温度达到 300 K 后曲线趋于平坦。」
6.7 **表内文字必须翻译**：表头、表元文字属正文，必须译；表中数字、单位符号、变量、缩写原样保留；表注与脚注标记（a、b、*、†）保留并翻译说明文字。

## 7. 引用与参考文献

7.1 **正文引用标注一律原样保留**：`[12]`、`[3–5]`、`[12, 14]`、`Author et al. (2020)`、`Smith and Jones [7]`、LaTeX 键 `\cite{...}`、`\ref{...}`；作者姓氏不译、年份不改、编号不动。
7.2 **参考文献列表不翻译**，整段照抄英文原貌：条目编号、作者、题名、期刊、卷、期、页码、年份、DOI 全部不改。
7.3 **禁止改动引用体系**：不得改编号顺序、不得新增或删除条目、不得合并或拆分条目、不得统一或修正条目格式、不得补全缺失的 DOI 或页码。
7.4 原文引用格式前后不一致时保持原样，不做统一。

## 8. 不翻译清单

| 类别 | 处理方式 | 理由 |
| --- | --- | --- |
| 参考文献条目 | 整段保留英文原貌 | 检索可追溯，格式由原文决定 |
| 数学公式本体与数学占位符 | 逐字复制 | 数学表达式无自然语言译法 |
| 变量、函数、参数、单位、运算符 | 保留拉丁字母与符号 | 译中文即失去定义与可复现性 |
| 代码、算法伪代码、命令行 | 原样保留标识符 | 标识符语义依赖字面拼写 |
| URL、DOI、邮箱、许可证编号 | 原样保留 | 唯一标识符，改动即失效 |
| 作者姓名与机构地址 | 保留原文拼写与顺序 | 署名身份与检索需要 |
| 图内图像文字（坐标轴、图例） | 保留英文原貌 | 属图片内容，译文层不可改 |
| 软件、系统、算法、数据集、基因、蛋白、化学物名 | 保留原文 | 专有名称，无通行译名 |
| 期刊、会议、出版社名称 | 保留原文 | 检索需要 |
| 原文引文块（block quote） | 保留原文，可附中文译文 | 引文须与原文逐字一致 |
| 公式编号、正文引用标注 | 原样保留 | 编号改动破坏交叉引用 |
| 表头表元中的数字、单位、缩写 | 原样保留（文字部分翻译） | 数值与符号不得改写 |

## 9. 结构映射

9.1 **章节标题对照**（必须按表映射，不得自创译名）：

| 英文标题 | 中文标题 | 英文标题 | 中文标题 |
| --- | --- | --- | --- |
| Abstract | 摘要 | Acknowledgments | 致谢 |
| Introduction | 引言 | References | 参考文献 |
| Related Work | 相关工作 | Appendix | 附录 |
| Background | 背景 | Supplementary Material | 补充材料 |
| Methods / Materials and Methods | 方法 / 材料与方法 | Highlights | 要点 |
| Results | 结果 | Graphical Abstract | 图形摘要 |
| Discussion | 讨论 | Keywords | 关键词 |
| Results and Discussion | 结果与讨论 | Funding | 资助信息 |
| Conclusion(s) | 结论 | Conflict of Interest | 利益冲突声明 |
| Data Availability | 数据可用性声明 | Author Contributions | 作者贡献 |

9.2 **层级与编号不变**：原文 `1.` / `1.1` / `2.3` 的编号与层级一一对应，不得增删编号、改层级、改序号；`Section 3.2` → 「第3.2节」。
9.3 **标题末尾不加句号**，去掉英文标题末尾句点与多余空格。
9.4 **Highlights**：标题译「要点」，逐条翻译，条目数与顺序不变，不得合并。**Graphical Abstract**：标题译「图形摘要」，图内英文不译，图旁说明文字翻译。
9.5 **摘要**：必须保持一段式，禁止拆段、禁止添加「目的」「方法」「结果」「结论」小标题、禁止添加原文没有的句子；摘要内数字、缩写、引用标注照抄；摘要不设压缩指标，逐句对应翻译。
9.6 **关键词**：逐词翻译，数量与顺序与原文完全一致，分隔符全篇统一为中文分号；缩写与专有名词保留原文（`machine learning` → 「机器学习」，`PCR` 保留 `PCR`，`ImageNet` 保留 `ImageNet`）。

## 10. 允许的增补与译注标记

10.1 **仅允许三类增补**：(a) 衔接性功能词（「本节」「如下」「即」），每自然段最多 1 处且不改变信息；(b) 术语首次出现处的英文括注（2.4）；(c) 译注标记。
10.2 **禁止其他增补**：解释性、评价性、总结性扩写一律禁止，包括「具有重要意义」「为后续研究提供参考」「值得注意的是」等原文没有的判断句。
10.3 **译注统一标记**：行内紧接被注释内容之后，格式为 `【译注：说明文字】`（全角方括号与冒号），单条不超过 60 字，只陈述问题与依据。固定词头两类：
   - 存疑类：`【译注：存疑——原句 "…" 指代不清，暂按…处理】`
   - 术语类：`【译注：术语——"…"无标准中文译名，暂译…】`
10.4 同一处译注只出现一次；译注不得替代翻译（不得只写译注而不给译文）。
10.5 **译注汇总**：交付时必须另附译注清单（按出现顺序列出所在小节、原文片段、译注内容）。

## 12. 常见错误对照表

| 英文原句 | 错误译法（机翻腔 / 错译） | 正确译法 | 错在哪 |
| --- | --- | --- | --- |
| The samples were heated to 80 °C. | 样品被加热到 80 摄氏度。 | 样品加热至 80 °C。 | 被动直译「被」；单位被译成中文 |
| We propose a lightweight network. | 我们提出……（后文改「本文提出」） | 本文提出一个轻量网络。 | 人称策略不统一 |
| A lot of studies focus on this task. | 一大堆研究关注这个任务。 | 大量研究关注该任务。 | 口语化 |
| The model reaches 92.5% accuracy. | 模型达到了约 93% 的准确率。 | 该模型取得 92.5% 的准确率。 | 数字被四舍五入，有效位数丢失 |
