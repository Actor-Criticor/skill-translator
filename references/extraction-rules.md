# 提取原理与人工复核清单（extraction-rules.md）

本文说明 `scripts/extract.py` 到底怎么"看懂"一篇 PDF、哪些地方它只能给概率性结果、
以及**哪些必须人工确认**。遇到结果可疑时，按第三、四节的调试入口直接看中间数据。

---

## 一、总体思路：能确定的确定，不能确定的标出来

PDF 是"排版结果"，不是"文档结构"。同一份论文，导出工具不同，内部结构可能完全不同
（段落可能是一整块，也可能被切成十几个小块；公式的分式可能是三个对象，也可能是一个）。
因此本技能的原则是：

1. **用几何证据推断结构**（栏间空隙、基线、横线、字号），而不是假设某种生成器；
2. 每一步都输出**置信度与告警**，机器不确定的地方显式标出来交人工；
3. **绝不静默编造**：宁可少还原一个符号并标记"需复核"，也不猜一个看起来合理的式子。

---

## 二、各环节的判定规则

### 1. 分栏（单栏 / 双栏）
- 取页面内宽度合理的文本块，在页面宽度 32%~68% 之间扫描"候选栏缝"；
- 评分 = 跨越该位置（左右都压线）的块数 + 与页面中线的距离；
- 跨界块 ≤ max(1, 块数/20) 时判定该页为双栏；
- 全篇按页投票（≥60% 的页为双栏 → 全篇双栏）。

**会出错的情况**：整页只有 1~2 列的稀疏页面、三栏排版、横排页（landscape）。
三栏会退化为"双栏 + 部分块归属错误"，此时阅读顺序需要人工抽查。

### 2. 阅读顺序
通栏元素（跨栏大图、通栏表格）把页面切成若干"水平带"；带内**先左栏自上而下、再右栏自上而下**。
被漏掉的块按位置兜底追加。`doc.json` 里每页记录了 `col` 与顺序，可核对。

### 3. 页眉页脚
出现在页顶/页底 9% 区域、且在多页重复出现的行，或纯页码行 → 标为 `header`/`footer`，不进入译文。
**会出错的情况**：首屏页眉带期刊名与页码（与其它页不同）时可能漏删；此时译文里会多出一行页眉文字，人工删掉即可。

### 4. 题注识别（图/表）
- 正则要求"编号后有分隔符"：`Figure 1.`、`Fig. 2:`、`FIGURE 3 |`、`Table 4.`；
- **必须有分隔符**，否则正文句 "Figure 1 shows …" 会被误判为图注；
- 题注块词数 > 90 的排除（题注不会那么长）。

**会出错的情况**：无分隔符的期刊体例（`Figure 1 A schematic …`）会被漏掉 →
表现为"图 N 定位失败"。处理：按第五节人工截图。

### 5. 图片定位（fig1~n）
以**题注为锚点**：
1. **先把"图内文字"从正文里摘出去**（坐标轴标签、图例、面板编号）：它们会被版面分析判为
   `body`，如果拿它们当"图上方最近的正文块"，候选带会被压到几 pt 高，图就会定位失败或
   抓到隔壁那张图（**实测踩过这个坑：fig1 与 fig2 抓到同一片区域，两张图字节完全相同**）。
   判据：≤12 词的短文本块，与图形簇相交、或横向 22pt / 纵向 25pt 内紧邻图形簇。
2. 取题注所在栏的水平范围，向上找到最近的正文块底边 → 得到"候选带"（同时被"上/下方别的题注"截断）；
   若带内没有图形，再试题注下方；带内若有多个图形簇，**只取离题注最近的那一个**。
3. 兜底顺序：整页离题注最近的大图形簇 → 离题注最近的大栅格图 → 标记 `missing` 交人工。
4. 把选中簇范围内的**短文本块**（轴标签/图例/面板编号）并入 bbox，外扩 5pt，按 400 DPI 渲染。
5. **同页去重**：已被前一张图占用的图形簇不再复用；定位后还会做两道安全网——
   bbox 与已定位图 IoU>0.8、或两张 PNG 文件字节完全相同 → 在该图的备注里写
   「疑似定位到同一幅图/定位重复，必须人工核对」。

**会出错的情况**：
- 题注在**图上方**且上方紧邻正文 → 候选带被正文截断 → 图被切掉一部分（脚本会先试上方再试下方）；
- 多面板图（(a)(b)(c)）间距大于 10pt 时可能被当成两簇，只取到一簇；
- 图片下方紧贴另一段正文时，若正文块恰好被判为"短文本"，会被并进图里。

### 6. 表格
两条路径 + 一条兜底，按优先级：
1. **PyMuPDF find_tables**（只用 `lines`/`lines_strict`）：适合**有竖线或完整网格**的表。
   会剔掉不合理候选（面积 > 45% 页面、行数异常），并要求与表题距离 ≤ 90pt。
   **质量分包含"行覆盖"**：区域内文本行有 6 行而只认出 2 行时不给高分（实测出现过
   "6 行压成 2 行却报 quality=1.00"）。行数可疑时会自动改用下面第 2 条的结果。
2. **文本几何重建**（`p2zlib.table_from_text`）：针对三线表、只有上下线的表、**无边框表**。
   行 = 按基线聚类；单元格 = 按自动求出的列间隙切分；列定义优先取表头的单元格位置；
   表头行数用 `\midrule` 的位置判定。**区域两个来源都试**：
   - 横线夹出的区域（`_table_region`）——对三线表最准，但会被下方公式的分式横线污染；
   - 按"带明显水平间隙的短行"聚簇得到的区域（`_shrink_rect_to_content`）——对无边框表更稳。
   两者都跑一遍，取质量更高者（实测：带竖线但数据行无横线的表只有第 2 条能还原出 6 行）。
3. 都不行 → **截图兜底**：范围优先用"重建实际用到的行"的并集，其次题注栏内的文本行簇，
   最后才是题注上下各一段；**范围超过页面 50% 会强制收窄并写入告警**。
   注意页面必须按列表里记录的页码取（所有页 rect 相同，用 bbox 反查会永远命中第 1 页——
   实测出现过"表格截图截到第 1 页整页"）。

**必须人工核对**：`tables-manifest.md` 看模式与质量分（质量 < 0.8 会写"行数可疑"）；
`LaTeX 三线表` 也要抽查 `tableNN.tex` 的数值是否串列。复杂表（多级表头、单元格内换行、
跨页长表）建议人工重写。

### 7. 行间公式
1. **找数学行**：① 所在块被判为数学块；② 数学字形占比 ≥0.32；③ 含"不可能是普通正文"的
   数学符号（Greek、∫∑√、±×≈ 等）**且本身不是散文**（散文判定：词数 ≥3 或字母数 ≥10，
   且数学占比 < 0.22）。
   **注意**：期刊常用"Times 正文 + CM 数学"（mathptmx 等），公式里的数字与拉丁字母是正文字体，
   靠字体名判数学会严重漏判；反过来只看符号又会把含 α、× 的正文行吸进来 —— 两个条件必须同时用。
2. **聚成一条公式**：按几何相邻 + 同栏聚合（纵向间隙 ≤ max(1.9×字号, 15pt) 或同一水平带，
   且横向必须接近：允许轻微负重叠但要求 x 范围相近）；编号行只吸附、不切分。
3. **吸收**：把落在候选范围内、或紧邻且带明确数学符号的"非散文"行并进来
   （嵌套分式的分子、大运算符的上下限、公式右侧的 `= 常数`）。
   一行只能属于一个候选（全局占用表），否则公式会被复制成多条。
4. **合并**：先按"共享同一行"合并互相包含的候选；再按几何关系合并
   （纵向间隙 ≤12pt 且横向相近）——这一步把矩阵的每一行、公式末尾的 `, α,β∈R.` 条件并回同一条。
5. **覆盖率自检**（防"静默截断"）：候选框内若还有非散文的数学行没被纳入，
   **强制把置信度压到 0.6 并写入"疑似截断"告警**，逼人工对照原图补全。
   这是针对"内容缺了 25%~75% 却拿着 1.00 置信度一路 confirm 到交付"这一实测事故设的闸。
6. **LaTeX 还原**（`p2zlib.run_to_latex` / `layout_to_latex`）：
   - **分式**：用细横线（高度 ≤2.2pt，含 `\rule` 填充矩形）定位，分子/分母按"横线上下 +
     x 落在横线范围内"取字符，**允许分式只占表达式的一部分**（如 `∂u/∂t = …`）；
   - **根式**：用 `√` 右侧的上横线确定覆盖范围（只取 √ 右侧字符）；
   - **大运算符上下限**：`∑∏` 取居中上下限；`∫∮` 按 LaTeX 语义取**右侧**上下限
     （基线更低者为下限）；一律以"本段主基线"为参照；
   - **上下标**：按字号比 + 基线偏移判定，按"基线分带、带内按 x 排序"排字（`10^{-3}` 不会被排成 `^{-3}10`）；
   - **矩阵/分段**：识别跨行大定界符（私有区字形 + 高度 ≥1.45 倍字号 + CMEX 字体），
     左+右成对 → `pmatrix/bmatrix/vmatrix`，仅左侧大括号 → `cases`；定界符左侧内容（如 `M =`）留在环境外；
   - **多行对齐**：只在"≥2 行、每行字符数 ≥4、关系符 x 对齐（偏差 ≤1 字号）"时输出 `aligned`；
     否则**一律展平**（盲目按行猜环境会产生大量垃圾草稿）。
7. **渲染与符号守恒**：见 `equations.py`；`--dpi` 用 `matrix=` 缩放实现（不要把 float dpi
   传给 `get_pixmap`，PyMuPDF 会抛 TypeError —— 实测 `--dpi 600` 曾直接崩溃）。

**会出错的情况（属正常，需人工修）**：
- 一条公式被拆成多条（共享同一原编号）→ 脚本会给出"原编号出现 N 次"的提示，人工合并；
- 一个公式被"过度合并"（相邻公式之间几乎没有正文间隔）→ 人工拆开；
- PDF 文本层缺字形（某些数学字体把大字形的上下限画成图形，抽取不到）→ **只有截图里能看到**，
  必须以 `eqNN_orig.png` 为准补上；
- 分式嵌套分式、多行公式中的 `\qquad` 对齐等复杂结构 → 草稿仅作起点。

### 8. 源文（供翻译）
- 行内公式还原为 `$...$`（直接照抄进译文）；**边界会把紧邻的数字/小数点吞进来**，
  避免出现 `4$5.0$`（45.0）、`29$8.15$`（298.15）这类需要人眼拼接的碎片。
- 行间公式替换为 `⟦EQnn⟧` 占位符，并在上方注释原编号与置信度，低置信加 `[!LOWCONF]`；
- 表格替换为 `⟦TABLEnn⟧`（表题另起 `>` 行），**表格区域内的文字不再重复输出**；
- **图区域内的文字**（坐标轴标签、图例、面板编号）也不进译文，只留一条
  `<!-- 图内文字（随原图保留英文，不翻译）：… -->` 注释备查
  （旋转文字常被抽成反序乱码，混进译文会误导译者）；
- 首页正文之前的标题/作者/日期写成 `<!-- front-matter（标题/作者/日期，不入章节计数） -->`
  并记入 `sections.json` 的 `front_matter` 标记，**不计入章节结构核对**（否则 F8 会误报）；
- `References/Bibliography` 标题之后标 `<!-- REFERENCES：以下内容不翻译 -->`；
- 运行页眉/页码按"数字归一化成 `#` 后跨页重复"识别并剔除（每页页码不同的期刊页眉也能删掉）；
- 词的连字符行尾断词合并（`signif-` + `icant` → `significant`），决策记录在 `manifest.json`。

**已知的源文瑕疵**（不影响翻译，人工顺手修正即可）：
- 行内公式边界偶尔切偏：如 `9$7.5$%`（原意 97.5%）、`$i-$th`；
- 上标被排到基数之前：`$1^{-3}0$`（原意 `10^{-3}`）；
- 字体连字（ﬀ/ﬁ/ﬂ）已自动还原为普通字母。

## 三、中间数据在哪（排查用）

| 想查什么 | 看哪里 |
|---|---|
| 每页的块角色/栏/阅读顺序 | `extracted/doc.json` |
| 图/表/公式的坐标、置信度、告警 | `extracted/manifest.json` |
| 表格的重建细节 | `extracted/tables/tables.json` 的 `notes`（列阈值、列定义来源、表头行数） |
| 公式的疑点与原文字符 | `extracted/equations/equations.md`、`eqNN_chars.json` |
| 断词合并决策 | `manifest.json` → `stats.dehyphenation` |
| 编译细节 | `paper/build.log`、`paper/build-report.json` |

## 四、手工修法（不改脚本的前提下）

```powershell
# 1) 图片切歪：用系统截图/看图工具裁好后覆盖同名文件（尺寸建议 ≥ 300 DPI）
Copy-Item my_crop.png <work>\extracted\figures\fig2.png -Force

# 2) 表格想手工重排：写一个新的 tableNN.tex（只写 tabular 本体），并改 tables.json 的 mode
#    {"01": {"mode": "latex", "file": "table01.tex", ...}}   <- mode 改回 latex

# 3) 公式：改 draft/eqNN.tex -> 重新渲染 -> 重新确认
python scripts/equations.py render --work <work> --only eq03
python scripts/equations.py confirm eq03 --work <work> --note "按 eq03_orig.png 逐符号核对"

# 4) 重新走一遍提取（改了 DPI/页码范围时）
python scripts/extract.py <pdf> --out <work> --dpi 600
```

## 五、人工复核清单（提取阶段，逐条勾）

- [ ] `fig1~n` 数量 = 原文插图数；编号与原文一致；每张都没有切掉坐标轴/图例/面板标签
- [ ] 没有把正文段落切进图里；没有把两幅独立的图并成一张
- [ ] 表格张数 = 原文表数；三线表数值抽查 ≥5 个单元格；截图兜底的表裁剪范围正确
- [ ] 公式条数与原编号对得上（有"同一编号出现多次"提示的已合并）
- [ ] 低置信公式（`[!LOWCONF]`）已逐条与原图核对
- [ ] `source.md` 通读一节，确认没有整段粘连、公式行没有残留在正文、参考文献区已标记
- [ ] 页眉/页码没有混进正文；作者单位、日期等元信息齐全（译文首页要用）
